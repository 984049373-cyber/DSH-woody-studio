# 去AI味清单（A-0+E2+E3）

写作风格层修订规范。适用于所有文本产出：剧本、细纲、大纲、笔记、回复、分析。**只改语言，不改内容；以减法为主，绝不新增信息。**

## When to Use

- 用户说「去AI味」「自然一点」「别像AI写的」「润色」
- 写任何剧本/细纲/大纲/分析文档时作为默认风格基准
- 修改用户原文时（只改语言层，内容红线不碰）

## 三条红线（防幻觉三铁律）

1. **只改语言，不改内容** — 删的是表达，不是事实
2. **以减法为主，绝不新增信息** — 不补新事实、不添新观点
3. **不脑补、不编造、不改因果** — 拿不准就保留原文

## 修订清单

### A 破折号限制用（不是禁用）
- 只用于后面紧跟**一句很简短**的解释或补充（这种可保留）
- 若要塞进一长串插入语，不用破折号（打断阅读、降低流畅度），改成拆句或正常句子成分
- 整段别扎堆

### B 对称/排比句打破对称（重点），意思不变
- 打破：`不仅…而…`、`不是…而是…`、`一方面…另一方面…`、`与其说…不如说…`、对称三段式「A是B，C是D，E是F」
- 别把"相关"升级成"导致"
- `不是…而是…` 尤其少用（出现频率过高）：能直接陈述就直接说（"其实是Y""真正起作用的是Y"），不必每次先否定再肯定

### C 凑三的排比收
- 用真正需要的项数；装饰性"三件事/三个原因"滥用要收
- 承载真实逻辑的单个"但/因此"保留

### D 无意义程度词删
- 删：非常、极其、十分、大大、相当、尤为、格外、显著地（非统计义）
- 删装饰性"重要性"词：关键、核心、至关重要、革命性、突破性、全方位、全面
- 判据：**删掉断言不变 → 删**
- 绝对词（所有/从不/唯一/首个/必须）不擅自删弱，拿不准就留

### E 空转提示语过渡 → 删开头
- 删：值得注意的是、需要指出/强调的是、有趣的是、不难发现、众所周知
- 删堆叠的"此外、另外、而且、再者、与此同时"

### E2 宣告式过渡删，直接说
- 删：说到底/归根结底/先说结论/划重点/总结一下/先记一句（后面内容本就看得出是核心，不用先宣告）
- **「一句话」类一律禁用（硬规则）**：一句话、就一句话、一句话说清、一句话说清楚、其实就一句话、核心建议只有一句、一句话讲清等一概不用。要点直接说出来，绝不先宣告"用一句话"

### E3 人为情绪化标签删，平实陈述
- 删：扎心的事实/残酷的真相/令人揪心/最让人担心的/不得不说/触目惊心/可怕的是
- 情绪标签删掉，事实平实说
- 温和关心语气（会更稳妥/不用太担心/心里也踏实）保留，不刻意煽情或制造焦虑

### F AI腔词汇换平实词
- 赋能、抓手、闭环、链路、维度（非专业义）、生态、图景、底层逻辑、深耕、彰显、绘就、勾勒出一幅…画卷、保驾护航 → 换最平实的说法

### G "-ing式"空尾巴删
- 删句尾"，凸显了/彰显了/体现了…其重要性"这种原地打转的尾巴
- 删"换句话说，<把上句重说一遍>"的赘述

### H 空泛大结论落回具体
- 删：「总而言之，这些…为…铺平了道路/具有深远意义/开辟了新方向」
- 删空话，不新编具体内容

### K 文绉绉/生僻词换最简单同义词
- 旨在>为了/想、藉由>通过、伴随>随着、诸如>比如、予以>给、进行+名词（空动词）>直接用动词、之于>对、较之>比
- **精确医学术语**（去势、转移、浸润、复发、缓解）不简化

### L 文学化比喻/拟人还原直白
- 删比喻意象：画卷、交响、基石、灯塔、在…的中心、踏上…的旅程、揭开神秘面纱
- 删戏剧化：令人震惊的是、范式转变
- 删拟人：细胞"想要决定/懂得/聪明地"
- 每段至多留一个最贴切的比喻
- 去比喻别改因果强度（"驱动/主导"含因果，属内容，别动）
- 固定术语别动

### M 套话/万能开头删或落回实义
- 删：近年来、随着…的发展、备受关注、日益受到重视、仍知之甚少、前景广阔、有望成为、值得进一步研究

### N 节奏单一/段首雷同
- 不动意思/术语/数字前提下，把连续相同的段首或句式适度变化、长短句交错
- 拿不准就别动

### O 多余括号补充
- 装饰性或纯重复的括号，折进句子或删
- **数字引用/缩写定义/单位/术语解释的括号一律保留**

### P 明令禁用词（一律不用）
- 说白了、脊背发凉、掰开揉碎了说、先说结论、直接给你答案、讲透了、值得一提的是、毛骨悚然
- 口语腔/宣告式/廉价惊悚，都是AI高频词；要表达的意思直接写出来

### Q 熟悉名词别加引号
- 已经介绍过、或读者本就熟悉的名词（免疫、疫苗、抗体、细菌、基因等），后文重复出现时不再加引号
- 引号只留给：首次提出的自造词、反语、或特意强调的字眼

### R 台词角色风格判据（剧本专用）
- 判据：**把这句台词换个角色说，还违和吗？** 不违和 = 台词没写出角色味，是「任何人都能说的AI通用腔」，要按角色身份/立场/口癖重写
- 剧本去AI味时逐句过一遍主要角色台词：角色甲的怯懦讨好、角色乙的蛮族直骂、角色丙的冷静陈述——各自的语感不可互换
- 群像反应同理：同一事件不同角色的台词必须体现各自视角，不能全是同一种「标准反应腔」

## 修订顺序建议

1. **P 禁用词**（硬扫一遍）
2. **E2「一句话」类**（硬规则）
3. **E3 情绪化标签**
4. **D 程度词 + B 排比对称**
5. **F AI腔词 + K 文绉绉词**
6. **G/H/E 过渡与空尾巴**
7. 最后通读：N 节奏、A 破折号扎堆、O 多余括号

## Common Pitfalls

1. **借"去AI味"改内容** — 只动语言层；事实、数字、因果、术语一律不动
2. **把"相关"升级成"导致"** — B 条，因果强度是内容，不可随意升降
3. **绝对词乱删** — 所有/从不/唯一/首个/必须不擅自删弱
4. **精确术语被简化** — 医学术语、专业术语保留
5. **括号一刀切** — 数字引用/缩写定义/单位/术语解释的括号必须保留
6. **对用户原文动手** — 用户写的内容（待定.md/笔记/定稿中用户原文）不修改，只按要求追加或经明确授权
