# 大纲创作规则

大纲创作的思考方法与结构设计规则。

## When to Use

- 用户说「写大纲」「设计主线」「规划剧情」「分卷」时加载
- 任何涉及故事整体结构设计的任务

## 先好看后合理（总铁律）

剧情规划先问「怎么写才好看」再倒推设定，不要先问「设定合不合理」（2026-08-11 用户纠正实例：纠结三师兄知不知道祖师存在合不合理，方向错了——重要的是怎么写才好看）。

执行顺序：先定最好看的场景 → 排冲突升级阶梯 → 设定服务于戏剧性。

## 六步创作法

### 1. 确定作品基调

先明确「情绪底色」——喜剧、热血、悬疑、沉重……基调决定所有后续决策的上限和下限。

### 2. 设计主角内驱力

内驱力是核心引擎——它决定主角「为什么做」。所有剧情行为必须能被内驱力解释。

**经典三段式弧线**：

| 阶段 | 内驱力 | 核心心理 | 行为模式 |
|------|--------|---------|---------|
| — | 外部事件激发的强烈情绪 | 「我不能接受」 | 复仇、变强、争一口气 |
| 二 | 变强后的满足和享受 | 「我有能力过得更好」 | 扩张、收集、享受权力 |
| 三 | 与他人羁绊催生的责任感 | 「我要守护」 | 主动保护、承担责任 |

**规则**：
- 内驱力非固定，随剧情阶段演变，每个阶段行为模式匹配内驱力
- 阶段之间需要转折事件，必须明确设计、有铺垫
- **内驱力驱动一切行为**——不能出现「因为剧情需要所以这么做」。同一场景，不同阶段的主角做完全不同选择

### 3. 设计主线结构

根据总集数拆分三条线：

- **中期线**：内驱力第一阶段最直接出口（如复仇），前期拉动观众
- **长期线**：贯穿全程的成长载体（如种田/扩张），为内驱力演变提供「变强」手段
- **伏笔回收**：已埋伏笔必须合理时机回收——不能太久忘掉，不能太快显小

### 4. 设计配角与关系网

配角是内驱力演变的催化剂。按阶段匹配：

| 阶段 | 配角类型 |
|------|---------|
| 早期 | 仇恨对象、引路人、早期伙伴 |
| 中期 | 后宫、享受型角色、展示实力的对象 |
| 后期 | 需要保护的人、让他意识到责任的人 |

**配角规则**：每个在场角色必须有自己行动逻辑；不能被「剧情需要」驱动；如果某场景无自己行动 → 考虑他是否该在场。

### 5. 分卷/分段

按内驱力转折点拆分大卷，不按集数均分。每卷结束 = 内驱力变化节点。每卷内部再拆为剧情段。

### 6. 剧情段设计

**三要素**——设计前必须同时确定：

| 要素 | 定义 |
|------|------|
| 事件起止（明线） | 开头和结尾各是什么事件——表层推进 |
| 情绪起止（暗线） | 所有人物的起始情绪和终点情绪——包括主角、反派、朋友、女主、围观者 |
| 长度规划 | 合理篇幅，决定后续细纲节拍数量 |

## 爽文奖励驱动机制

**核心公式**：完成任务 → 奖励结算 → 两种奖励

| 类型 | 作用 |
|------|------|
| **甜头** | 立即爽或解决燃眉之急——即时满足 |
| **铺垫** | 为下个关键剧情提供能力/道具——解决困难+装逼打脸，最好兼顾 |

**设计顺序**（倒推法）：先确定下个关键剧情节点 → 反推需要什么能力/道具 → 设计获取这些的任务 → 结算为甜头+铺垫

## 大剧情篇幅配比原则（用户实战经验总结）

- **观众无感的铺垫要压缩**：只为后续推动、当下无情绪价值的铺垫线（如反派暗线）只占一集尾部一小场，禁止放开头、禁止独立成段——它是突如其来的，观众对它无感
- **高潮戏=铺垫×3以上**：打脸/高潮戏篇幅至少是铺垫篇幅的三倍；铺垫1集→高潮至少3集
- **高潮前先写对方视角**：打脸戏不能上来就打，要先正面展开对方的剧情（现状、算计、作死升级过程），把对方立住再打
- **过渡流水账1集收**：目标明确的执行过程（买齐材料、赶工、危机解除）是流水账，1集内搞定，不配多集
- **开副本集先拉期待感再进副本**：①告诉观众要做什么+为什么 ②必要性、危机感、困难全部立住 ③主角仍毅然决然出发——这才是大剧情的开启
- **集尾钩子分层**：开副本集的钩子拉本副本的期待；阶段收尾集的钩子才拉下一大阶段的期待（如新药剂、新目标）
- **已知困难后必起未知异变**：主角通过已知、铺垫过的考验（常规可结束点）时，必须起异变引入未知困难，拉起新节奏把大高潮继续往上推——只靠已知困难撑不满高潮篇幅

## Common Pitfalls

1. **内驱力不连贯** — 主角行为突然不符合当前阶段（愤怒期享乐、享乐期牺牲）
2. **转折突兀** — 内驱力阶段转换没有铺垫事件，读者感觉「人设崩了」
3. **配角工具化** — 角色只在需要时出现，没有自己的行动逻辑
4. **明暗线脱节** — 只写事件推进没写情绪变化，细纲展开时发现没有暗线可追
5. **奖励机制不合理** — 甜头只爽不铺垫 → 剧情推进乏力；全靠铺垫不爽 → 读者骂水

## 中途回顾工作流

回到半成品作品续写时的标准流程：

1. **扫文件定进度**：find 扫描作品下所有 .md 确定进度（search_files 对中文内容可能误报 0，降级用 grep/find）
2. **并行读核心资料**：作品信息、总大纲、待定.md 必读；总大纲可能为空——为空时从定稿反推进度
3. **抽关键集通读**：按剧情弧线抽关键集的定稿通读，恢复剧情语感
4. **盘点三张表**：弧线进度 / 角色状态 / 伏笔清单
5. **续接方案**：只给方向 + 选择题，与用户确认后再动笔，不直接开写
