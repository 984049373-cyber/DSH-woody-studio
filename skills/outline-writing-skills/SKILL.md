# 细纲创作技巧

剧情节的拍设计方法、模块模板库与叙事元素标签体系。

## When to Use

- 用户说「写细纲」「设计剧情」「推进第X集」时加载
- 任何涉及剧情结构设计的任务

## 前置铁律

动笔前不可跳过：

1. **场景最小化** — 事件链设计时，场景越少越好，能不转场就不转场。优先塞入已有场景，新建场景需承载多个事件
2. **先定场景后分模块** — 先确定本集有哪些场景，再在每个场景内用模块编排情绪和事件。禁止跨场景排列模块链
3. **写前自检** — 每集动笔前读取上一集定稿，检查：场景空间关系、已交代信息（避免重复）、角色情绪承接
4. **技术判断由角色说出** — 观众无法通过画面判断技术细节对错。技术优劣的判断必须让懂行角色用台词说出

## 五步工作流

| 步骤 | 内容 | 完成后检查 |
|------|------|-----------|
| 1 | 确定大的写作目标，每个目标对应一个大模块 | 目标明确，不模糊 |
| 2 | 用情绪顺序排出大模块链（情感是主链条），检查逻辑断点，插入小逻辑模块补位 | 情绪链条完整，无跳跃 |
| 3 | 给链上每个模块打叙事元素标签（探索/冲突/出场/打断/反应/悬念/转折） | 每模块至少 1 个标签 |
| 4 | 用标签去小模块模板库匹配可用的执行模板 | 标签和模板对齐 |
| 5 | 套用模板骨架，参考经验微调，输出细纲 | 每个模板的经验都检查过 |

## 叙事元素标签

所有剧情设计必须标注以下标签之一：

探索 冲突 出场 打断 反应 悬念 转折

## 节拍设计四步法

### 1. 确认大纲输入

明确剧情段的事件起止（明线头尾）、情绪起止（暗线头尾——所有人物）、总篇幅。

### 2. 按比率分配节拍

篇幅越长节拍越多，但不过多也不过少。参考：1.5 集 → 若干节拍，按作品节奏调整。

### 3. 逐个设计节拍

每个节拍同时含两个维度：
- **明线**：发生什么事件/爽点/反转
- **暗线**：该事件推动哪些人物的情绪从什么状态变到什么

规则：
- 节拍事件不能完全重复，性质可相同但中间逻辑必须不同
- 明线只有两种：**反转**或**递进**
- 情绪首尾相接：上节拍落点 = 下节拍起点
- 层层推高直到情绪顶点

### 4. 检查节拍链

- 明线：事件从头到尾形成完整推进链，无断点或重复
- 暗线：人物情绪逐层递进（如 惊讶→震惊→愤怒→孤注一掷→绝望），无跳跃倒退

## 大模块模板

### 首次场景初探·五段抛物线
**标签**：探索、悬念、打断 | **情绪链**：恐惧→暂稳→好奇→困惑→震撼

| 段 | 名称 | 功能 | 可用小模块 |
|----|------|------|-----------|
| 1 | 交代场景 | 观众和角色同步到达 | — |
| 2 | 心理变化→行动 | 从慌乱推导出需要探索 | 多人反应顺序、角色出场 |
| 3 | 探索中塑造场景 | 通过探索建立场景「味道」 | 探索+分析停顿 |
| 4 | 发现与分析 | 到达核心谜题，短暂消化 | 发现惊叫、探索+分析停顿 |
| 5 | 外力打断 | 外部事件强制换场 | 外力打断 |

**经验**：探索动作后必须有分析停顿；信息分层级释放，密度递增；外力不能是角色自己的决定。

### 失败蓄势·主角待发
**标签**：冲突、出场、反应、悬念、转折 | **情绪链**：紧张→被宣判→缓和→自信→崩塌→压迫→释放

配角先挑战同一任务并失败 → 配角水平越高、失败越意外，蓄势越强 → 主角登场。

## 小模块速查

| 模块 | 标签 | 用途 |
|------|------|------|
| 角色出场 | 出场 | 新角色首次亮相 |
| 多人反应顺序 | 反应 | 事件后多人依次反应 |
| 探索+分析停顿 | 探索 | 发现后停一步分析 |
| 发现惊叫 | 转折 | 关键发现时的冲击感 |
| 外力打断 | 打断 | 外部事件强制中断 |
| 突发事件反应者 | 反应 | 旁观者反应 |
| 反派嚣张 | 冲突 | 反派示强/挑衅 |
| 衔接模块 | — | 情绪/场景过渡 |
| 挑战者临场紧张 | 冲突 | 挑战者赛前心理 |
| 行家技术判断 | 冲突 | 技术对比由角色台词呈现 |
| 自信完成→自检崩塌 | 转折 | 完成感→发现失败的落差 |
| 主角物理打断 | 打断 | 主角直接出手中断 |

## 写作技巧

- **反派伪善台词技巧**：伪善型反派台词特征——语气温和、表面讲亲情、实质是侵占、且自我深信（他真的觉得自己在做好事）。正确方向示例：把侵占说成"功劳归家型"（"这个家没有我不行"）
- **重复结构的情绪放大**：「A—B—A」重复结构，同句出现两次，中间夹对比内容，放大情绪冲击
- **高潮后的克制收尾**：情绪高潮后用轻描淡写收尾，给观众「呼气」时刻；高潮接高潮会削弱两者

## Common Pitfalls

1. **忽略场景边界** — 模块必须在场景内运作，跨场景排列会丢失空间连续性
2. **情绪链跳跃** — 相邻节拍情绪差距太大没有承接 → 观众脱节
3. **只写明线忘暗线** — 每个节拍必须同时有事件（明）+情绪变化（暗）
4. **标签随意打** — 用标签是为了匹配模板，不是走过场
5. **创意选项用 clarify 弹窗** — 讨论方向、创意选项直接在对话框列选项让用户选，不用 clarify 弹窗
