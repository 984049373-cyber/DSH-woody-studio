# 短剧张力设计（打脸/装逼/高潮）

短剧张力场景的核心创作观，适用于所有打脸/装逼/高潮剧情的节奏设计。

## When to Use

- 设计打脸、装逼、登场、高潮、卡点（一卡/二卡）剧情
- 设计多集连续大高潮
- 任何需要「先抑后扬」「先烘托后装逼」的场景

## 铁律一：主角驱动

剧情由主角的目标和行动驱动，反派只是阻力/回应，不是剧情引擎。设计剧情先问「主角要做什么」，不先问「反派要干什么」。

- 主角每集要有主动决策（立目标、定方案、出手）
- 反派的动作是被主角行动激起的回应——「反派被逼出来」，不是「反派自己冒出来」
- 反面示例：整段围绕「反派要干什么」展开，主角被动应对 = 反派驱动 = 违背宗旨

## 铁律二：气氛烘托是装逼的精髓

**反派和群众不把气氛烘托起来，主角的装逼就没有任何意义。装逼装得再好，不如一次完美的气氛烘托。**

标准节奏（反派先表演，主角压轴）：

1. **氛围铺垫** — 围观群众议论/指指点点，制造悬念与期待
2. **反派亮阵** — 反派带人登场，阵容先唬人
3. **反派表演** — 当众展示实力——让观众亲眼看到"他们真的很强"，不是嘴上说强
4. **反派贬低** — 把主角踩到地上，观众憋气等反转
5. **反派主动攻击** — 直接动手，冲突点燃
6. **主角远程回应** — 人未到、招先到，轻描淡写显示碾压差距
7. **主角压轴登场** — 带人亮相 + 金句台词

## 主角出手前的情绪渲染（憋屈蓄满再出手）

主角出手/登场前，必须先把情绪顶到顶点——观众憋着这口气，出手才爽。五层递进 + 点火：

1. **对手踩** — 当众贬低下结论
2. **徒弟委屈** — 自己人被欺负到眼眶发红
3. **长辈心酸** — 无力感
4. **群众倒戈** — 围观者开始不信
5. **反派补刀** — 得意挑衅
6. **主角OS点火** — 看着徒弟红眼眶、师父佝偻背影、四周指点目光，护短之心燃起
→ 然后才出手

## 铁律三：一卡/高潮节奏

- 反派越嚣张、展示越充分，主角登场越爽
- 主角的第一击必须是「远程、轻描淡写」，制造「你们拼尽全力，我还没认真」的落差
- 登场台词要金句化，卡点收在钩子上

## 铁律四：角色有自己的策略（非工具人）

角色比观众以为的更聪明——每个人有自己的时机判断和算计：

- 懂法的人不在强拆时讲理，而是在有实力背书后才亮出道理
- 每个角色要有自己的立场、选择、城府，不能被「剧情需要」推着走

## 铁律四补：行家不降智，大宗师不是小人（反派尊严）

打脸对象越是行家/大宗师，越要保住他的专业判断与宗师气度：

1. **行家认出铁证后不再质疑** — 铁证落地后，角色的挣扎要**换层面**：不否认事实，而是重新定义标准（「这一局我认输。但这不过是外物小技！」）。他认的是这局输了，争的是这局能不能代表全部
2. **大宗师认赌服输，赖账是小人行径** — 输了当众认账，风骨保住才配当对手。他的「不认输」不是保面子，是**求一个答案**（如验证传承真伪）
3. **挑战对象选最强，不选最弱** — 大宗师主动挑战的是全场最强，不是刚入门的新人；「以大欺小，胜之不武」是风骨不是装的
4. **辈分反杀可作上场第一句** — 重要角色被推上场后，第一句用辈分压对手，呼应前面立过的辈分

## 大高潮设计（矛盾集中爆发）

多集连续大高潮要点：

1. **同场景集中** — 多集钉在同一场景连续对决，不转场
2. **对手阶梯升级** — 小怪（1-2集）→ 中间人 → 大Boss（带专业力量），逐波打脸
3. **每层战场不同** — 武力层 → 法理层（论证/规则）→ 道统层（传承/身份）→ 官方层（裁决/背书），一层比一层高
4. **奖励结算** — 大高潮结束 = 主角目标直接达成，用「正名/官方认可」收尾。注意：官方表态不一定放当集——结算可以延后，先用「反派升级」钩子吊住观众
5. **主角驱动贯穿** — 即使大高潮，主线仍是主角目标，反派只是来阻挠
6. **情感高潮与结算收尾分集** — 大高潮最重的情感戏和收尾拆成两集：前一集把情感顶到顶点，后一集从容收束。宁拆开，勿一集塞满导致节奏仓促。**收尾有两种走法，以用户最新设计为准**：
   - 走法A「从容收束」：收徒 → 反派灰溜溜退场 → 官方表态 → 正名
   - 走法B「反派升级钩子」：收徒 → 权威认可 → **反派气炸** → 叫人强攻 → 手下犹豫 → 反派加钱压过恐惧 → 全面上 → **主角一声断喝**——集尾钩子=冲突升级，官方表态/正名延后
7. **集尾情绪承接** — 上一集结尾的情绪状态（震惊爆发/悬念钩子）是下一集开头的起点。集尾钩子要干净：情绪爆发点砸完就收、不拖尾巴。下一集从爆发点开始消化情绪，过程不能跳：震惊→失态确认→崩溃→追问→沉默消化→恢复体面认输→再转下一冲突。情绪承接属于**下一集的开场，不属于上一集的尾巴**

## 铁律五：层次递进（多对手打脸的节奏）

多波/多对手的打脸剧情，逐级往上顶，主角永远压到最后：

1. **对手逐级登场** — 小喽啰 → 头目 → 大Boss，每一级都是「拦住主角」的节奏。主角全程保持「不恋战」的主动方姿态——表态完就走，是反派追着拦他，不是他等着反派
2. **出手有层次** — 徒弟打小的，师父打大的；不是主角一出来全灭
3. **主角出手前必有「扫描判断」OS** — 看穿对方底细，OS 把差距掀给观众看
4. **反派也有认知过程** — 惊讶 → 自我说服 → 再动手；不无脑嚣张、不降智
5. **金句 callback** — 反派贬低主角的话，主角最后原样回敬
6. **清算反派要「演」出来** — 不能一句「灰溜溜退场」带过：逼问 → 分析 → 动手教训 → 喜剧点

## 铁律六：事实推动剧情（不用纯语言）

**剧情推进靠「事实/事件」，不靠角色「嘴说」。主角证明身份、剧情反转，都要有可视化事实支撑。**

- 主角证明身份，不解释，直接给「证据演出」：信物合璧 → 化作光幕 → 播放影像留言——观众亲眼所见，比一百句解释都硬
- 影像留言要「每句讲到实处」——不能是口号，要有具体细节 + 人生感悟 + 情感
- **留言是「画面与心声分离」的内心独白**：△画面 = 正在做的事，台词 = 内心OS（没说出口的思念）；只有临终托付是唯一「说出口」的话——画面是沉默的一生，OS 是憋了一辈子没说出口的思念，叠出电影感
- 现场权威反应佐证（专家疯抢记录），真实性的裁判权交给旁观者
- 主角的情感：**静默流泪 + OS 内心独白**——眼泪是画面，OS 是心声；OS 常承担三职能：交代背景事实、逻辑闭环、情感爆破
- 反面教材：靠主角「淡淡说出当年点滴」——纯语言推动，苍白无力

## 铁律八：关键信息与交锋都要「写实」

短剧观众很多人不看屏幕只听声音——**关键信息、角色认知、心理变化必须用台词说出来，不能只靠△旁白或画面**：

- 角色「明白/认出」要喊出来，不能写△「他终于明白」
- 反派的心理崩塌要念出来
- 场景过渡要具体化

## 论辩交锋必须写实（至少三轮对话）

**「逐条反驳」「双方僵持」「不屑」不是画面描述，是至少三轮的实打实对话交锋**：

- 每一轮：一方抛证据 → 对方否定/不屑 → 再抛 → 再驳，有来有回
- 典型三轮结构：正史文献 →「方志一句话不算证据」；功法典籍 →「托名之作多了去了」；实物碑刻 →「可能是后人伪造的」→ 反将一军 → 对方语塞 → 恼羞成怒 → 此时才落「僵持不下」
- 对手态度要有递进：不屑 → 语塞 → 恼羞成怒，不能从头到尾一个表情

## 论道/法理战的金句对打

正名型冲突（论证/法理/道统层面）的关键手法：

- **用对方的逻辑反打** — 对方否定你，你用同一句式回敬
- **物证 > 口证** — 论道僵持时拿出信物，观众看得见摸得着；主角凭另一半合璧/认出，闭环坐实
- **主角可主动出手破局** — 论道吵不出结果时，主角不吵架，直接当众展示实力，让质疑者亲眼看「真东西」；但这只是第一击，紧接着仍要落到论道反击上（金句对打），武力展示≠直接胜利
- **官方角色要有「前戏」** — 领导/权威到场前先给动机戏 → 到场先旁观 → 全程见证 → 最后表态裁决，分量才足。**旁观戏的因果要完整**：下属必须先主动请示，领导才有「不急」可拦——前一句的「请示」是后一句「拦下」的因

## 认亲/信物相认套路（论道终局）

用信物坐实身份时，不能「我认得→合璧」直线完成，必须走完整套路（套路不纯熟 = 缺铺垫）：

1. **回忆先行** — 先开小回忆建立情感（师徒相处 + 告别）。回忆必须单独建场。关键设计：小徒弟不是只哭，要立誓——一语成谶的悲剧感
2. **信物要有「交付时刻」** — 信物的情感重量来自交付场景
3. **感慨** — 回到现实，主角感叹
4. **专家鉴定（权威背书）** — 现场专家验出年代，物证走程序
5. **反方亮牌** — 对方义正言辞亮出己方信物
6. **主角行动不嘴炮** — 不解释，直接掏出另一半信物
7. **神迹** — 两枚信物相互吸引、发光、在空中合为一体（特效点）
8. **反方破防 + 认亲金句** — 瘫坐「这不可能！」→ 主角走向他

**认祖归宗不是结尾，是开始**——这句金句之后才是认祖归宗的完整展开：

1. **反方质问** — 你是谁？为什么有信物另一半？
2. **主角不答，放证据** — 信物融合升空化光幕（事实推动）
3. **影像留言** — 一生四个阶段，最后临终托付
4. **专家疯狂** — 拍下来！记录！重大发现！（权威佐证 + 打断反派节奏）
5. **请打假的人当场倒戈跪拜**
6. **主角流泪、扶起、收徒** — 静默流泪 → 收徒台词

## 铁律七：反派必须在场见证自己的败北

主角的高光时刻，反派必须在场，亲眼看着自己的底牌一张张变成打自己脸的巴掌：

- 他花钱请来打假的高人，当众倒戈
- 他花钱请的专家，被「历史发现」吸走注意力，没人理他
- 全程反应线：看好戏 → 脸色骤变 → 气急败坏 → 成为孤家寡人 → 铁青收尾
- 反面教材：认祖归宗大戏里反派消失，主角高光没有「被碾压的对象」，打脸不闭环

## 命名逻辑

- **宗门以祖师道号命名** — 不能另起无关名字
- **功法/剑诀名携带宗门前缀** — 技法名是宗门品牌的延伸
- **反派逐级实名** — 爪牙 → 老板 → 高人，不占位（XXX/XX）
- **群像角色命名映射人生轨迹** — 一组相关角色的名字暗示各自的人生选择，名字本身就是角色命运的微缩标签，观众一听就知道谁是什么路数
- **祖师小名 = 主角当年的昵称** — 认亲时的情感引爆点，回忆里先喊出来
- **回忆中的角色形象要明确** — 性别年龄具体，不能含糊
- **官方角色保持模糊身份** — 领导就叫「领导」，不写具体部门/职级；用他的「前戏」和「全程见证」立角色，不用头衔立角色

## 大高潮开启前的准备（「集多功能」原则）

设计大高潮的开启场，不要一集只完成一个目标。**每集要同时完成三四个叙事目标，并且看起来是自然发生的，不是在完成任务清单。**

示范——一集成果展示同时完成：

1. **展示弟子实力（打脸弹药上膛）** — 用「成果汇报」自然带出，不单独拿一集写修炼过程
2. **重要人物聚齐（大高潮证人席）** — 领导在场、庆祝氛围，人全在，不是硬凑
3. **埋下一条线** — 一句话交代，观众知道有事要发生
4. **引出冲突（钩子收尾）** — 有人通报来客，集尾炸雷

**关键原则：好看优先于设定**

设计高潮时，先问「怎么写才好看」，再倒推设定。不要先问「这个角色知不知道这件事、合不合理」——设定服务于戏剧效果，不是反过来。

**大高潮开启前必须到位的清单：**

| 要素 | 说明 |
|------|------|
| 弟子实力已练成 | 不是新手侥幸赢，是「教出来的就是比你强」——打脸才有说服力 |
| 围观阵容到齐 | 前面出场的重要人物集中到场——人越多，打脸的证人越多 |
| 主角态度已定 | 主角对对手是什么态度？——决定整段基调 |
| 对手有正当理由 | 对手不是无脑来找茬，他有自己的道理，这样打脸才有层次 |

## 大高潮的「从弱到强」叙事顺序

高潮弧线的剧情排列，**从弱到强逐步推进**，不是一上来就最强的对最强的：

1. **先温后炸** — 温情/日常铺垫在前，冲突在后爆发，落差才有冲击力
2. **对手的第一关不是最强对手** — 先碰小角色，展示对手实力和动机，再逐级升级到打脸核心
3. **每一关都给对手新的理由发怒** — 不是反复打同一架，而是每过一关对手有新的不满，冲突在升级

## 大高潮的对位设计（反派出牌 vs 主角团接牌）

大高潮的打脸层次不是随意排列，而是**对位设计**——反派出什么牌，主角团就有一张对等的牌接住。

### 第一步：人物清单排序法

设计大高潮出场顺序前，先把在场**所有人**（含龙套）列出来，按重要顺序从低到高排序。已在前菜冲突中用过的角色从序列中剔除，不参与后续打脸。

示范对位表：

| 对位层 | 反派的牌 | 主角团接牌的人 | 打的是什么 |
|--------|---------|--------------|-----------|
| 1 | 记者（舆论施压） | 弟子/领导（官方身份接） | 合法性 |
| 2 | 比专业技能 | 弟子 | 传承正统性 |
| 3 | 比武（硬实力） | 大徒弟 | 实力 |
| 4 | 道统质疑 | 主角（收尾） | 身份 |

**核心铁律：谁出的问题，对位的人接——不能错位。**

### 第二步：咖位决定出手顺序

**角色重要程度决定出手先后——越重要越靠后，主角永远压轴。** 可直接从排序表推出，不需要额外理由。

- **硬规则**：咖位决定先后——技艺比拼（输了只是面子）→ 比武（输了被踩）→ 主角收尾（道统层面，最重）。从软到硬，每一步冲击力比上一步重
- **软功夫**：如果某个重要角色提前出场了，但按咖位要靠后——必须从剧情里找一个**合理障碍**让观众接受延后。两种做法：
  - 做法A：让对手主动跳过她——不是她退了，是对手不屑接她的招，她被晾在台上
  - 做法B：**对手挑战全场最强（主角），主角再把重要角色派上场**——这样重要角色上场是主角安排的（正当），反派大宗师的气度也保住（他挑战的是最强）

### 第三步：铺垫与高潮体量匹配

**大高潮的集数要和铺垫集数成正比。** 每层打脸都需要完整的「扬→打→反应」空间，对手的认知转变也要给足时间（不屑→认真→震撼→崩溃→服气，每一步不能跳）。

## 一场比试拆三集（比试三集法）

「一场比试如何拉长而不注水」：

1. **第一集造势，不碰比试本身** — 先打「人」：辈分反杀、护徒、舆论围攻、官方背书、拆台——把所有人拉上场、把矛盾摆上台面，比试还八字没一撇
2. **第二集立赌，不进入比试** — 对峙 → 探修为 → 约赌 → 对手加码（赌注升级）→ 亮比法 → 自信独白 → **集尾抛悬念：主角不接招，派个意想不到的人上场**
3. **第三集正戏，内部再分三层** — 对手戏（身份反差/嘴仗）→ 过程展示（蒙太奇+主角点评）→ 反转三连，集尾钩子停在震惊爆发

核心手法：

- **一集一个焦点，不贪** — 打人、立赌、比试各一集；每集只干一件事，干完就收，钩子砸在集尾
- **一个悬念拖满一整集** — 第二集尾抛悬念，第三集整集来解
- **用「人」撑起「事」** — 比试本身一集就比完了，看点全在人物上
- **装逼三段式打满** — 对手先充分表演 → 群众围观造势 → 主角方压轴登场一击定音。「扬」得越足，砸下来越狠
- **后续比试套用同结构** — 一场大比试至少3集起步

## 打脸妙招库

- **一弹指羞辱** — 打脸不必硬碰硬：主角方随手一指弹开对手，轻描淡写比打飞更羞辱
- **反派的绝学=主角方的入门课** — 对手亮出压箱底招式，主角方一愣：「这不是师父刚教我的吗！」——他引以为傲的绝学是人家刚学的入门课
- **同款招数硬碰硬** — 主角方用同一个招数对撞，正版碾压残篇——让对手输在自己最自信的领域
- **题眼金句点破** — 打斗中一句点破胜负根源，把「拼实力」升级成「拼传承」
- **主角最后才下场，赐机缘而非镇压** — 大高潮主角收尾不打服，而是：肯定对手初心 → 神迹展示 → 实质赐予 → 对手自己开悟升华。被打服的人只服一时，被点醒的人才真心归宗

## 偶遇型打脸（回乡/重逢线）

主角回旧地的打脸线，常见误区是写成主动寻仇。正确结构：

- **打脸是副产品** — 主角有正当正事在身，正事目标从头贯穿，打脸在办事过程中偶遇发生
- **主角心态先立住** — 「你们对我已经不重要了」：不恨、不寻仇、重逢无波澜。收口给题眼金句
- **作死方自己凑上来** — 打脸对象先抢戏，把旧事主动摆上台面，主角只负责当众收尾碾压
- **打脸三连拆法**（铺垫×3→高潮的落地形态）：①对方视角铺垫+抢戏作死 ②当众戳穿（物证铁证+权威质问）③清算 → 对方恼羞反扑 → 人赃并获收尾
- **群像留一个悔者** — 全家清算外留一个悔罪者，比满门清算更有余味

## 后高潮弧线设计（高潮收口之后怎么写）

大高潮弧线结束后，故事不能就此平掉。一季的后半段通常是三段式：**高潮弧 → 发展弧 → 危机弧**。三段的节奏、写法、目标完全不同。

### 发展弧（4集左右）：繁荣中的暗流

高潮结束 = 主角团阶段性胜利。发展弧的任务不是制造新冲突，而是**展示胜利果实 + 角色成长 + 暗埋下一轮危机**。每集仍需同时完成3-4个目标（同「集多功能」原则），不能变成流水账。

1. **成果爆发集** — 外部反应，喜剧底色，关键谈判，集尾钩子=主角发现自身变化
2. **日常建设集** — 扩建、招生、角色弧闭合，集尾钩子=进一步松动
3. **目标升级集** — 主角顿悟新力量来源，宣布加速蓝图，集尾钩子=暗埋危机种子
4. **繁荣顶峰集** — 各方合作蒙太奇，但主角持续不安，集尾钩子=明确的不祥预感

**发展弧的喜剧节奏**：两集之间必须穿插轻喜剧段，作为高潮弧密集打脸后的节奏缓冲。但喜剧不能独立存在——每段喜剧都服务于世界观展示。

**主角的暗线**：发展弧的每一集，主角都有一条暗线在推进——这条暗线是连接发展弧和后续危机的桥梁，不能省。

### 危机弧（5集左右）：日常打破 + 格局升级

危机弧是整季的收束段，从角色驱动的个人冲突升级为世界观级别的威胁。节奏结构：

1. **暴风雨前的日常** — 先给角色一段轻松日常，然后突然打破。日常越温馨，打破越震撼
2. **弟子独当一面** — 高潮弧里被师父护着的弟子，此刻独自面对威胁。这是「主角教导成果」的最终回报
3. **真相揭示 + 备战启动** — 主角向核心弟子解释威胁本质，推动备战。信息量最大的一集
4. **科技/法术融合 + 新能力解锁** — 碰撞（喜剧底色），装备成型。集尾钩子=更大威胁
5. **季终集** — 成果展示 → 大威胁降临 → 主角集结全员列阵 → 金句台词收尾

**危机弧的弟子独战要点**：
- 弟子不是轻松碾压，而是苦战获胜——找到弱点、师父教的招式成为关键一击
- 独战过程必须念出关键信息
- 击败后主角赶到，从残留物中发现更大真相——弟子解决表层危机，主角揭示深层危机

### 季终收尾原则

- **不闭合，留裂缝** — 季终集不把所有线索收完，大威胁在最后一集降临并定格，留给第二季
- **主角金句收束主题** — 最后一句台词应点破整季主题，既是总结也是开场
- **全员列阵的画面感** — 最后一幕必须是群像——视觉上传递「传承开枝散叶」的主题
- **日常喜剧作为对照** — 季中段的喜剧日常和季终的战争列阵形成强烈反差

## 拉情绪=层层递进，不是堆事件

用「几个令人气愤的事凑情绪」是错的。情绪要一条递进链，每一级比上一级更紧。

**铁律：动手永远是最后一步。** 一开场就在抢/在打=没有情绪可言。压迫要先「围而不动」。

递进链模板（以「劫匪逼粮」为例）：
1. **围而不抢** — 刀出鞘堵住出路，压迫感先立住（不动手）
2. **亮明动机与时间压力** — 动机给合理性+死线
3. **逼迫回合制升级** — 每回合压力加一级
4. **被逼到墙角后的反弹** — 绝望转战斗意志，情绪在此拧到顶
5. **动手**
6. **主角在最后一格切进** — 爆喝救场救在刀落之前

pitfall：①一上来就在抢（没情绪）；②愤怒事件清单凑数；③递进中插入散戏——散戏一出现情绪就断。**篇幅不够说明情绪没做足，答案是把递进链写满，不是往结尾续戏。**

## 对峙/认输场面：禁纯嘴炮，必须动作化

反派被围、认输、摊牌的场面最容易写成一问一答的嘴仗。拉锯式嘴炮 = 没有画面、没有信息增量。

- **压缩对峙**：认输戏对白压到「一问一答」级，不逐条拉锯；超过两轮的回合，把其中一轮换成动作
- **底牌用动作演，不用话说**：反派「我还剩一张牌」不能只靠台词宣告——直接让他动手，场面本身就是台词
- **算计要能被主角一句话还原成机制**：让观众才信「这一步他早算好」；机制最好回收前集埋过的台词
- **主角一句短评定性，不解释不论证**
- **反派换维度挣扎**：认输后不纠缠同一局，换战场继续。他的不服靠新的计算与风骨，不靠撒泼（呼应铁律四补「挣扎要换层面」）

**恐怖场面写法**——递进链：

1. **异变预告**：印记浮起
2. **龙套一句短问**钉住恐怖——观众听到的比看到的更瘆人
3. **递进三拍**：血雾 → 嚎叫溃烂 → 化为血水
4. **静物反差**：刀剑当啷落地（人没了，兵器还在）
5. **旁写无一人逃脱**：一句带过逃散者——比再拍一轮正脸更寒
6. 音效独立行；△只写结果，不做生理/液体渲染

**超自然道具/能力必须落在本作世界观体系内，且有来源**：世界观里没有科技时不能写现代道具；反派逃生手段的道具来源要在同一场先交代，能力才有因果

## Common Pitfalls

1. **主角先出场碾压** — 反派没表演完就出手，张力为零
2. **反派驱动** — 整段剧情以反派的谋划为主线，主角被动接招
3. **群众缺席** — 打脸没有围观者反应垫底，装逼落地无声
4. **实力展示靠嘴说** — 反派强不强必须演出来，不能只说
5. **主角一人全灭** — 没有徒弟/配角先挡、主角压轴的层次
6. **认亲/相认直线化** — 「我认得→合璧」一步到位，缺铺垫
7. **名字占位** — 反派/高人用 XXX/XX 占位不实名；宗门名与祖师道号脱节
8. **认祖归宗当收尾** — 认亲金句是**开始**，后面还有完整展开
9. **反派缺席自己的败北** — 主角高光时刻，反派必须在场
10. **纯语言推动剧情** — 没有可视化事实支撑
11. **论辩一笔带过** — 没有至少三轮对话交锋；专家态度无递进
12. **关键信息靠旁白** — 必须变台词（含角色OS）
13. **写剧本前没重读待定.md** — 用户随时改写待定.md，待定是唯一权威设计源。凭记忆/旧推演写剧本=大错。动笔前先完整读待定确认最新设计；**用户改写的原文不允许修改**（只能追加，或经明确授权后补充，发现笔误只提醒不擅改）；创作中角色称呼也可能随用户改写演变，以最新待定为准。**对话中途用户也会随时改文件**——每次展示/引用/继续设计前先重新读取
14. **一集只塞一个目标** — 大高潮前奏集每集应同时完成3-4个叙事目标
15. **从设定推导剧情** — 先定戏剧效果再倒推设定
16. **忘记主角对对手的态度** — 主角对不同对手的态度不同，决定整段高潮的基调
17. **打脸层次错位** — 设计大高潮先列对位表：每层必须对等
18. **重要角色提前出场后没法延后** — 必须找一个合理障碍
19. **铺垫和高潮体量不匹配** — 每层打脸需要完整的「扬→打→反应」空间
20. **行家质疑自己刚认出的铁证** — 铁证落地后挣扎要换层面，不能否认事实
21. **反派写成小人** — 拒绝认输必须源于信念，不是保面子
22. **剧情线没收完就跳下一条** — 先把当前剧情线完整收掉，再设计下一段弧线
23. **集尾情绪不承接/情绪过程跳步** — 下一集开头必须从爆发点开始消化
24. **群众议论用上帝视角信息** — 围观者只能议论他们肉眼可见的东西，内行信息只放在知情者OS里
25. **集尾钩子自作主张补场** — 用户设计停在悬念处就停在悬念处，不擅自加场、不提前放后续梗
26. **用户给节拍后自行续编节拍** — 节拍到哪就写到哪，落点必须停在用户指定的最后一句台词。要补内容先问
27. **对峙/摊牌写成纯嘴炮拉锯** — 压到一问一答，其余回合换成动作与场面
