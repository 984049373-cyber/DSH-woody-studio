# WooDy 写作技能索引

> 本文件是全部跨作品写作 skill 的**唯一索引**，由 Woody 维护。
> 维护纪律：技能注册、变更、废弃必须同步更新本文件，始终保持「索引 = 实际注册」。
> 随插件附带的是初始版（仅含核心技能）——你自行注册的新技能，请按维护规范登记并扩充本文件。

## 一、技能清单

### 核心技能（随 WooDy 插件分发）

| 名称 | 用途 |
| --- | --- |
| screenplay-format-spec | 剧本格式规范：字数标准、格式铁律、镜头指引、成稿自检清单 |
| outline-creation-rules | 大纲创作规则：六步大纲法、主角动机弧、奖励驱动机制、人物网络设计 |
| outline-writing-skills | 细纲创作技巧：节拍设计方法论、模板库（2 大 12 小模块）、叙事元素标注系统 |
| short-drama-tension-design | 短剧张力设计：打脸/装逼/高潮场面与高潮后弧线的结构方法 |
| de-ai-flavor | 去 AI 味：语言风格层修订清单，只改语言不改内容，以减法为主 |

## 二、维护规范

### 1. 注册新技能

1. 在用户级 skill 目录（`~/.dsh/skills/`）新建目录，**目录名即技能名**，必须为小写 kebab-case（`^[a-z0-9]+(-[a-z0-9]+)*$`），且不得与已有技能重名
2. 目录内创建 `SKILL.md`，frontmatter 必须包含两个字段：
   - `name`：与目录名完全一致
   - `description`：一句话说明「什么情况下使用本技能」
3. 技能正文用中文撰写；配套参考资料放 `references/` 子目录，配套脚本放 `scripts/` 子目录
4. 在本文件「技能清单」中登记一行：名称 + 用途（必要时可自建分组小节）

### 2. 变更技能

- 修改技能内容：直接编辑对应 `SKILL.md` 及其子目录文件，改动即时生效
- 仅当 `description` 的用途描述发生变化时，同步更新本文件表格中的「用途」列；其余改动不涉及本文件

### 3. 废弃技能

- 删除该技能的整个目录
- 从本文件表格中移除对应行

### 4. 边界

- 核心技能（5 个）由 WooDy 插件统一管理与更新：修改其内容是被允许的（插件同步会保护人工改动），但**不得在核心技能内混入自建内容**——自建经验一律注册独立技能
- 与写作无关的技能不登记在本文件
